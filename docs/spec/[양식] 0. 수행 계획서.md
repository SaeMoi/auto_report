## 0-6. 수행 규칙 (RoE)

- [ ] 허용 기법: \[웹 공격, 계정 대입 시도(횟수 제한), 권한 상승, 내부 이동\]
- [ ] 금지 기법: DoS, 실사용자 계정 사용, 악성코드 배포
- [ ] 자동 스캐너 사용 기준: \[일정 주기에만 사용 가능\]
- [ ] 테스트 계정: \[계정명, 권한에 대한 표 작성 필요\]
- [ ] 민감 데이터 취급: 개인정보는 마스킹해 증거로만 남기고, 프로젝트 종료 후 \[ \]일 안에 파기
- [ ] 진행이 막혔을 때: 화이트팀 승인을 받아 다음 단계 권한을 받은 뒤 이어서 수행함(threat card)
- [ ] 서버 직접 확인: 필요한 경우 화이트팀 승인을 받아 서버에 접속하고, 공격으로 바뀐 사항을 직접 확인할 수 있음
